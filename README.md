# Dynamic World Engine

A project for experimenting with dynamic, evolving game-world systems.

## Project status

This repository is under active development. Implementation details and supported features should be documented here as they become stable.

## Development

1. Clone the repository.
2. Install the dependencies required by the project.
3. Follow the project-specific setup and run instructions as they are added.

## Configuration and secrets

- Keep API keys and other credentials out of source control.
- Use local environment/configuration files for secrets.
- Commit only safe example configuration, with placeholder values.

## Contributing

Use feature branches and pull requests so changes can be reviewed before they are merged into `main`.
